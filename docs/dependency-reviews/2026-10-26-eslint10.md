# ESLint 10 compatibility review

PR #30 updates the root ESLint dependency from 9.39.5 to 10.13.0. The package
and lockfile remain scoped to that upgrade; TypeScript stays at 6.0.3 and the
approved Worker runtime/Undici overrides are retained.

Next.js 16.4.3's ESLint configuration accepts ESLint >=9, and its documentation
supports both ESLint 9 and 10. Some nested React/accessibility plugins still
declare only ESLint 9 peer ranges. The lockfile retains their compatible nested
dependencies; this change uses ordinary npm ci without forced or legacy peer
installation and keeps all lint rules enabled.

The original head passed complete CI. Before integration, the updated branch
must pass the complete Linux gate and cloud Apple Silicon packaging/lifecycle
gate against current dev, including native packaging and the approved ledger
regressions. These checks determine readiness; peer warnings alone are not a
claim of compatibility.

TypeScript 7 in separate PR #22 remains excluded: its CI fails because the
current typescript-eslint explicitly rejects TS 7.0. That migration requires a
separate tooling compatibility change.
