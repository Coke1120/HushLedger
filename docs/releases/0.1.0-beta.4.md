# HushLedger v0.1.0-beta.4

- Adds a native Apple Silicon macOS app with its own bundled Node/Worker runtime,
  stable window sizing, responsive monthly composition charts and ECB refresh
  fixes.
- Keeps accepted accented account/category names exportable in full-ledger
  backups while preserving ASCII case-duplicate checks and backup compatibility.
- Advances transaction and transfer versions monotonically, rejecting stale
  updates and deletes even when edits share a millisecond.
- Adds Cloudflare's opt-in security-audit skill with its MIT notice and pinned
  provenance. The skill does not run automatically.
- Publishes the actual app ZIP, build provenance, installation notice and SHA-256
  checksums after cloud macOS verification and a download integrity check.

Download HushLedger-0.1.0-beta.4-macos-arm64.zip for the application. GitHub's
automatically generated source archives are separate downloads.

This is a beta preview for Apple Silicon and macOS 13.5+. It is ad-hoc signed,
without Developer ID signing or notarization; macOS may block downloaded apps.
No quarantine removal or Gatekeeper bypass is included. Back up the intended
ledger before replacing an installed app. The application retains the existing
Application Support data location; this release adds no schema migration beyond
0022. No real ledger data is bundled or used in verification.

Cloud CI verifies unit/compatibility tests, types, lint, production Worker build,
integration and the extracted app's native launch/quit. Interactive native file
dialogs, real-user upgrade scenarios and Intel Mac execution are not validated
by that smoke. Package and download provenance identify the exact source commit.
